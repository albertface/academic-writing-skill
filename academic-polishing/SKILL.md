# Academic Polishing

## Core Workflow

1. Identify the document type, target audience, field, and requested edit depth. If these are not stated, infer them from the text and keep changes conservative.
2. Preserve the author's claims, evidence, technical meaning, citation markers, numbers, equations, terminology, and hedging unless the user explicitly asks for substantive rewriting.
3. Diagnose before rewriting: check paragraph purpose, thesis or topic sentence, unity, coherence, evidence support, sentence structure, word choice, and academic tone.
4. Revise from global to local: organization first, paragraph logic second, sentence-level clarity third, grammar and mechanics last.
5. Return the polished text plus concise notes when useful. For high-stakes academic work, flag unresolved logic, evidence, citation, or scope issues instead of silently smoothing them.

## Editing Modes

Use one of these modes unless the user specifies another:

- **Light polish**: fix grammar, word choice, punctuation, and flow while preserving sentence order and most wording.
- **Standard academic polish**: improve clarity, cohesion, concision, paragraph flow, academic tone, and sentence variety while preserving meaning.
- **Structural revision**: reorganize paragraphs, strengthen topic sentences and transitions, remove off-topic material, and suggest missing evidence. Use this only when the user asks for deeper revision or the text clearly needs it.
- **Diagnostic review**: provide issues and revision guidance without rewriting the full text.

## Non-Negotiables

- Do not fabricate citations, sources, findings, statistical values, sample sizes, limitations, or methodological details.
- Do not make claims stronger than the supplied evidence supports.
- Keep discipline-specific terminology intact unless it is clearly misused.
- Preserve citation style and in-text citation placement unless correcting an obvious mechanical issue.
- If the original is ambiguous, choose a cautious revision and note the ambiguity.
- For non-native academic English, prioritize clarity and natural scholarly phrasing over ornate vocabulary.

## Default Deliverables

For short passages, provide:

1. Polished version.
2. Key edits, limited to the most important changes.
3. Remaining issues, only if meaning, evidence, or structure remains uncertain.

For long manuscripts, work section by section and provide a brief editorial summary after each section.
